# LIMIS Feedback Module

Встраиваемый модуль обратной связи и оценки удобства портала для жителей города Нарва на стеке **PHP 8.5 / MariaDB 11 / Redis**, разработанный в строгом соответствии с фирменным стилем и дизайн-системой **LIMIS** (Narva Linnavalitsuse Linnamajandusameti Infosüsteem).

Включает:
- Клиентский доступный виджет опроса (на эстонском и русском языках);
- Защищённый публичный API приёма ответов без использования PHP-сессий;
- Административную панель с интеграцией сессионной роли LIMIS (`Peakasutaja`);
- Фоновый скрипт автоматизированной регламентной очистки данных;
- Полный набор автоматических unit- и integration-тестов (41 тест).

## Навигация по документации проекта

Документация модуля разделена по сферам ответственности:

1. **[INTEGRATION.md](./INTEGRATION.md) — Техническая интеграция и развёртывание:**
   Пошаговая инструкция для инженеров и системных администраторов: развёртывание бэкенда, настройка прав MariaDB (принцип Least Privilege), подключение Redis rate limiting, встраивание клиентского виджета (HTML data-атрибуты, SPA JavaScript API), подключение к сессиям LIMIS (`$_SESSION['active_role']`), настройка расписания `bin/purge.php` (Task Scheduler / cron) и скрипт отката.

2. **[COMPLIANCE.md](./COMPLIANCE.md) — Нормативные стандарты и безопасность:**
   Детальная карта соответствия регуляторным требованиям:
   - **GDPR:** минимизация собираемых полей (без IP, email, URL, user ID), псевдонимизация rate limit в Redis, срок хранения 180 дней, дисклеймер и ссылка на условия обработки данных города Нарва, защита от CSV Formula Injection.
   - **E-ITS:** аутентификация, RBAC (`Peakasutaja`), подготовленные выражения PDO, одноразовые HMAC-токены, honeypot, fail-closed защита при сбое Redis, ограничение прав СУБД.
   - **EN 301 549 / WCAG 2.1 AA:** семантика `<dialog>`, изоляция фокуса (Tab trap), `inert` для фона, управление экранным диктором, закрытие по `Escape`, фокусная рамка `--ee-focus: #ffcc00`, зум до 400%, 100 баллов в Google Lighthouse.

3. **[ASSUMPTIONS.md](./ASSUMPTIONS.md) — Допущения, компромиссы («костыли») и ответственность:**
   Откровенный разбор архитектурных компромиссов, вынужденно применённых в ходе автономной разработки:
   - Почему реализован автономный режим логина `standalone` и как перевести его в `limis`;
   - Почему применён двухуровневый stateless HMAC-токен без сессий;
   - Зачем разделены `data-page-key` (клиентский счётчик) и `data-page` (категория в БД);
   - Почему написан собственный сокетный клиент Redis без расширения PECL;
   - Ограничения модального окна без Shadow DOM и ручные флаги критических операций (`setCritical`);
   - Матрица разграничения ответственности между модулем и командой внедрения LIMIS.

## Системные требования

- **PHP 8.5** с расширениями `pdo_mysql` и `mbstring`.
- **MariaDB 11** (отдельная база данных `utf8mb4`).
- **Redis 6+** (порт 6379, атомарный rate limiting с часовым TTL).
- **Node.js 18+** для встроенного тестового раннера (`node --test`, без npm-зависимостей).
- **HTTPS** на всех обслуживаемых страницах.

## Быстрый запуск для локальной разработки и проверки

1. **Создайте базу данных:**
   ```sql
   CREATE DATABASE limis_feedback CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

2. **Примените миграцию:**
   ```sh
   mariadb limis_feedback < migrations/001_install.sql
   ```

3. **Создайте конфигурационный файл:**
   Скопируйте `config/config.example.php` в `config/config.php`, задайте реквизиты подключения к MariaDB и сгенерируйте секрет:
   ```sh
   php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"
   ```

4. **Задайте тестовый пароль администратора для режима standalone:**
   Сгенерируйте хеш пароля:
   ```sh
   php -r "echo password_hash('ваш_пароль', PASSWORD_DEFAULT), PHP_EOL;"
   ```
   и укажите его в `admin_hash` в `config/config.php`.

5. **Запустите полный автоматический набор тестов:**
   ```powershell
   powershell -ExecutionPolicy Bypass -File bin/test.ps1
   ```
   Скрипт проверит синтаксис всех PHP-файлов, доступность Redis, выполнит 22 unit-теста виджета и 19 интеграционных проверок API и панели администратора (всего 41 тест).

   *Для проверки реальной сквозной записи в тестовую БД:*
   ```powershell
   $env:LIMIS_TEST_ALLOW_WRITE = "1"
   powershell -ExecutionPolicy Bypass -File bin/test.ps1
   Remove-Item Env:\LIMIS_TEST_ALLOW_WRITE
   ```

   *Для быстрой очистки тестовых записей:*
   ```powershell
   powershell -ExecutionPolicy Bypass -File bin/test.ps1 -Clean
   ```

6. **Запустите локальный PHP-сервер:**
   ```sh
   php -S 127.0.0.1:8080 -t public
   ```

7. **Откройте в браузере:**
   - Публичная тестовая страница и виджет: `http://127.0.0.1:8080/`
   - Панель администратора: `http://127.0.0.1:8080/admin/tagasiside.php`

## Сводка результатов приёмочного тестирования

- **Автоматизированное тестирование:** все 41 проверка выполняются успешно через `bin/test.ps1`.
- **Принцип наименьших привилегий СУБД:** подтверждена стабильная работа под пользователем только с правами `SELECT, INSERT, UPDATE, DELETE, LOCK TABLES`.
- **Цифровая доступность (EN 301 549 / WCAG 2.1 AA):** 100 баллов в Google Lighthouse 13.4.1, масштабирование до 400%, полная навигация без мыши и поддержка экранных дикторов.
- **Дизайн-система:** стили виджета и тестовой страницы полностью приведены к дизайн-системе LIMIS (токены `--ee-*`, цвет шапки `#24578A`, контрастный фокус `#ffcc00` / `--ee-focus`).
